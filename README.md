# Titanic Data Analysis (EDA)

## Objective
To perform data cleaning and exploratory data analysis on the Titanic dataset.

## Dataset
- Source: Kaggle Titanic Dataset
- Records: 418
- Features: PassengerId, Survived

## Steps Performed
1. Data Loading
2. Data Exploration
3. Data Cleaning
4. Data Visualization

## Key Insights
- The dataset contains no missing values
- Survival is a binary variable
- Majority of passengers did not survive

## Tools Used
- Python
- Pandas
- Matplotlib
